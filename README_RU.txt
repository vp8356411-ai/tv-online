ТВ онлайн — PWA

Загрузите ВСЁ содержимое этой папки в корень репозитория GitHub Pages:
index.html, manifest.webmanifest, sw.js и папку icons целиком.
Не переименовывайте index.html и не загружайте только один файл.
Затем откройте опубликованный HTTPS-адрес сайта.

iPhone/iPad: открыть сайт в Safari → Поделиться → На экран Домой → Добавить.
Android: открыть в Chrome → меню ⋮ → Установить приложение / Добавить на главный экран.
Компьютер: открыть в Chrome или Edge → значок установки в адресной строке или кнопка «Установить».

Важно: приложение открывает интерфейс отдельно от браузера, но прямой эфир требует интернет.
Service Worker работает на HTTPS (GitHub Pages подходит). Некоторые потоки в исходном списке
используют HTTP; браузер может блокировать их на HTTPS-сайте как смешанный контент.
Доступность каналов зависит от самих потоков, региона и прав на просмотр.
